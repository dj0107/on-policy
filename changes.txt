[C] 보상 함수 — 신규 항목 추가 (논문에 없음)
────────────────────────────────────────────────────────────────────────────────

C1. r_untracked  (lam5 = 5.0)
    내용: 어떤 UAV도 타겟 k를 탐지 못하면 -lam5 per target
    이유: prod_loss는 연속값이라 binary 탐지 실패를 강하게 페널티하기 어려움

C2. r_detect     (lam7 = 20.0)
    내용: 타겟 k를 1대 이상 탐지하면 +lam7 per target
    이유: 논문 보상은 전부 음수(패널티) → 탐지 시 양수 보상이 없어 gradient 약함

C3. r_approach   (lam6 = 5.0)
    내용: 각 타겟에 대해 팀 내 가장 가까운 UAV 거리 기준
          r_approach += max(0, 1 - min_dist/200) * lam6  [per target]
    이유: 논문 원본에는 거리 기반 항이 없음.
          탐지 끊기면 F_kt/prod_loss 모두 위치와 무관한 상수 gradient가 됨
          → UAV가 "어디로 가야 하는지" 신호 자체가 없어 재탐색 학습 불가
    주의: 현재 min_dist (팀 최솟값) 기준이라 나머지 UAV는 gradient = 0 (free-rider)

────────────────────────────────────────────────────────────────────────────────
[D] BFIM / PCRLB 수식 변경
────────────────────────────────────────────────────────────────────────────────

D1. 재귀 공식
    논문 코드: J_k = F_inv.T @ J_{k-1} @ F_inv + Q_inv + 측정정보
    현재:      J_{k|k-1} = [F @ J_{k-1}^{-1} @ F.T + Q]^{-1}     ← Tichavsky 1998 표준
               J_k = J_{k|k-1} + 측정정보
    이유: 논문 코드 공식 사용 시 Q_inv 대각~800,000이 J를 1스텝에 지배
          → F_kt → 0 (모든 방법론 "100% quality"로 보임), 지표 무의미

D2. Lambda 행렬
    논문: Lambda = diag([1, 1, dt, dt])   (위치+속도 성분 모두 포함)
    현재: Lambda = diag([1, 1, 0, 0])     (위치 성분만)
    이유: PCRLB로 "위치 추정 오차"만 측정하는 것이 논문 의도에 부합

D3. 측정 잡음 분산 floor
    논문: sigma_r_sq = sigma_r0_sq / snr   (floor 없음)
    현재: sigma_r_sq = max(sigma_r0_sq / snr, 1e-3)
          sigma_theta_sq = max(sigma_theta0_sq / snr, 1e-7)
    이유: SNR 매우 클 때 R_t → 0 → 역행렬 수치 불안정 방지

D4. sigma_w_sq (프로세스 잡음)
    논문: 5.0
    현재: 0.1  (학습 조건; evaluate_trained.py도 0.1로 맞춤)
